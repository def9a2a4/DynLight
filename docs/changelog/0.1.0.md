# v0.1.0 - custom messages, admin toggle, PlaceholderAPI

> **Upgrading from 0.0.1:** just replace the jar. On first start DynLight creates
> `plugins/DynLight/messages.yml`; your `config.yml` and saved player settings carry over.
> There's one new permission, `dynlight.others` (ops by default). A player without it who runs
> `/dynlight enable <name>` now gets "no permission" instead of toggling their own lights.

- **Every message is customizable.** All chat messages now live in
  `plugins/DynLight/messages.yml`, using [MiniMessage](https://docs.advntr.dev/minimessage/format.html)
  formatting (colours, hex, gradients, bold...). Restyle or translate them, set one to `""` to hide
  it, and apply changes with `/dynlight reload`. Messages you haven't changed, or that are missing
  from an older file, use the defaults.

- **Admins can turn lights on or off for other players.** `/dynlight enable <player>` and
  `/dynlight disable <player>`, with the new `dynlight.others` permission. It works for offline
  players too, and an online player is told who changed their lights.

- **PlaceholderAPI support.** With [PlaceholderAPI](https://modrinth.com/plugin/placeholderapi)
  installed, DynLight adds `%dynlight_status%` (enabled/disabled, text set in `messages.yml`) and
  `%dynlight_enabled%` (`true`/`false`) for scoreboards, tab lists, chat formats and so on.
  PlaceholderAPI is optional.

- **Better help.** `/dynlight` and `/dynlight help` show the version, a short description, every
  command you can use, and links to the GitHub repo and the Discord.

- **Tested on Minecraft 26.x.** Every change is now checked on Paper and Purpur 1.21.11, 26.1.2,
  26.2 and 26.3.
