# v0.1.1 - log flood fix

> **Upgrading from 0.1.0:** just replace the jar. Your config, messages and player settings carry over.

- **No more log flooding when lighting fails.** If updating lights kept failing, DynLight printed
  the whole error, one line at a time, on every update (several times a second), until the console
  was unreadable. It now logs the error once with its stack trace, and logs again only if the error
  changes or comes back after the lights recover.

- **Quieter startup and shutdown.** Removed the "DynLight plugin enabled!" and "disabled!" lines.
  The server already prints its own line when each plugin is enabled or disabled.
